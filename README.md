# dsh-plugins

xypshot 的 DeepSeek Harness (DSH) 插件合集与插件市场索引。

## 插件列表

| 插件 | 版本 | 说明 |
|---|---|---|
| [dsh-llm-quota-board](plugins/llm-quota-board/) | 0.1.0 | 查看设置 → 模型中已部署的全部供应商和模型的余额与额度 |

## 通过插件市场安装

在 DSH Web 端 **插件 → 发现（Discover）** 中添加本索引：

```
https://raw.githubusercontent.com/xypshot/dsh-plugins/main/index.json
```

添加后即可搜索「额度」或 `quota` 并一键安装。

## 手动安装

也可以把 `plugins/llm-quota-board` 目录下载到本地，在 **插件 → 添加插件** 中指向该目录。
